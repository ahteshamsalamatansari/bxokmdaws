# Node REST API Example

A realistic Node.js REST API with authentication built using Express, MongoDB/Mongoose, and JWT.

## Features
- User registration and password hashing using bcrypt.
- JWT login authentication.
- Full CRUD API for posts with user ownership checks.
- Centralized error handling.
- Basic test suite.

## Setup
1. Copy `.env.example` to `.env` and configure your variables.
2. Run `npm install` to install dependencies.
3. Start development server using `npm run dev` or run tests with `npm test`.
